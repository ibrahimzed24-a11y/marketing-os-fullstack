How a real task runs

  1. OS → POST n8n webhook /webhook/marketing-os-task
  2. n8n → routes by pipeline → calls Antigravity / LLM / tools
  3. Agent reads harness files in /uploads
  4. Agent returns JSON + Admin Report markdown
  5. n8n → POST OS /api/webhooks/n8n → Task → In Review
  6. Admin approves → Delivered → Client sees it
