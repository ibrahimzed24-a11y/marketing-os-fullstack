# helm — Brand Kit & Guidelines

## Identity
- **Name:** `helm` (always lowercase in wordmarks)
- **Positioning:** A warm, human-governed workspace for research, sales, and creative operations.
- **Personality:** Calm, uplifting, clear, non-technical.

## Color Tokens
- **Ivory Canvas (`#FAF7F2`):** Primary app background
- **Pure Surface (`#FFFFFF`):** Elevated panels and cards
- **Midnight Plum (`#2D223A`):** Primary wordmark, headings, and dark icon tile
- **Cobalt (`#4C6EF5`):** Primary actions, active links, outer horizon arc
- **Sunlit Peach (`#FF9E6D`):** Warm highlights, inner horizon arc, momentum accents

## Files Included
- `svg/helm-logo-stacked.svg` — Hero / auth / splash lockup
- `svg/helm-logo-horizontal.svg` — Topbar & sidebar lockup
- `svg/helm-icon.svg` — Standalone horizon mark
- `svg/helm-icon-plum.svg` — Rounded square app icon on Midnight Plum
- `svg/favicon.svg` — Browser favicon
- `tokens/helm-tokens.css` — Drop-in CSS custom properties
- `tokens/tailwind-helm-theme.json` — Tailwind theme tokens
- `manifest/site.webmanifest` — Web app manifest
